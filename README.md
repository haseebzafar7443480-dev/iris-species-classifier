# Iris Flower Species Classifier

A multi-class Machine Learning classification project predicting Iris flower species (Setosa, Versicolor, Virginica) using physical measurements.

## Performance Comparison
| Algorithm | Test Accuracy (%) | 5-Fold CV Mean (%) | CV Std Dev (%) |
| :--- | :--- | :--- | :--- |
| KNN (K=5) | 93.33 | 96.67 | 3.12 |
| Decision Tree (depth=3) | 96.67 | 93.33 | 2.04 |
| Logistic Regression | 93.33 | 95.83 | 2.64 |

## Key Insights
- **Setosa** is linearly separable and achieved 100% classification accuracy across all models.
- **Decision Tree (depth=3)** gave the best balance between interpretability and test accuracy.
